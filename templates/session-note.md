# Session note: date or session ID

Copy to `inbox/session-notes/<date-or-session-id>.md`. It remains non-canonical even if committed.

- Session/source: bounded identifier, not raw transcript content
- Date or range: exact bounded period
- Temporary purpose: why this note is retained
- Status: active | closed | superseded
- Supersedes/superseded by: path or none

## Notes

Record only minimized, non-secret temporary context. Do not present it as durable truth.

## Durable follow-up

List any deduplicated lesson that may warrant a later proposal or separately approved canonical edit. No promotion occurs from this note alone.
