# Memory proposal inbox

When `write_model` is `propose_then_approve`, create one focused proposal per durable lesson. Use [templates/proposal.md](../templates/proposal.md).

A proposal must state the target file, evidence or provenance, rationale, proposed text, and whether approval is still required. Pending proposals are not bootstrap context and must not be described as saved memory.
