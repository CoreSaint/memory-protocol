# History ingestion

Never inspect historical sessions without explicit user approval. Record the approved source, date range, and scope in the resulting proposal; do not copy raw transcripts into canonical memory.

1. Discover available session sources with host-native tools.
2. Export or read only the approved scope.
3. Extract durable user preferences, correction patterns, verified project facts, and proven workflows.
4. Retain source pointers or hashes where practical so claims can be audited.
5. Place findings into focused proposals or canonical files according to the write policy.

History is evidence, not automatic truth. Prefer facts repeated across sessions or tied to concrete paths, commands, and user corrections.
