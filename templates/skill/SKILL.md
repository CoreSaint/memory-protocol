# Skill template

Copy this file to `skills/<skill-name>/SKILL.md`, then replace its frontmatter with exactly `name: <skill-name>` and one non-empty `description`.

## When to use

State the triggering conditions.

## Procedure

1. State deterministic or safe steps.
2. Identify required tools and optional fallbacks.
3. State validation and escalation conditions.
